# Проверка на Bitrix24 — 4 ноября 2026 года

Это ранний снимок до добавления полей и роботов. [Итоговая проверка того же дня](portal-check-2026-11-04-release.md) описывает актуальное состояние тестовых процессов.

Портал: `b24-aug0be.bitrix24.ru`. Проверка проведена через интерфейс Bitrix24 в локальном чате. REST API, вебхук и промежуточный сервер не использовались.

| Действие | Проверенный результат |
| --- | --- |
| Создание тестового процесса договоров | [«ТЕСТ: Договоры локального агента»](https://b24-aug0be.bitrix24.ru/crm/type/1040/list/category/0/), шаблон «Список». При создании отключена опция «Делать новые воронки доступными для всех». |
| Создание тестового процесса корреспонденции | [«ТЕСТ: Корреспонденция локального агента»](https://b24-aug0be.bitrix24.ru/crm/type/1046/list/category/0/), шаблон «Список». Та же опция отключена до сохранения. |
| Создание записи договора | [«ТЕСТ: договор без реквизитов — проверка агента»](https://b24-aug0be.bitrix24.ru/crm/type/1040/details/1/), ID 1. Сохранённая карточка показала событие «Создан элемент». |
| Создание записи корреспонденции | [Запись ID 1](https://b24-aug0be.bitrix24.ru/crm/type/1046/details/1/) с исходным названием «ТЕСТ: входящее письмо — проверка агента». Она появилась в списке процесса и открылась из него. |
| Изменение записи корреспонденции | Название изменено на «ТЕСТ: входящее письмо — создание и изменение проверены». После перезагрузки карточки новое название сохранилось; история карточки показывает оба названия. |

Оба процесса и обе записи оставлены в портале как тестовые. Шаблон «Список» показал поле «Название» и возможность добавления полей, но другие поля не настраивались. Договорная запись не содержит реквизитов, а запись корреспонденции не содержит отдельного направления, даты, номера или связи с проектом. Автоматическая нумерация и защита от одновременного присвоения одинаковых номеров не реализованы и не проверялись. Для рабочих процессов нужна согласованная схема полей и правил доступа.

Проверка подтверждает создание, открытие из списка и изменение тестового элемента в одном портале. Она не подтверждает работу на других порталах, с реальными договорами или письмами, при выключенном ПК либо без входа в Bitrix24.
